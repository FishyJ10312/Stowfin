# 安装与授权

[English](INSTALL.en.md) · 简体中文

适用于轻扫 **1.9.0 Beta（构建 23）**，Apple Silicon / arm64。

应用在英文界面显示为 **Stowfin**，在简体中文界面显示为**轻扫**。

**当前安装包使用本机自签名，暂未使用 Developer ID 签名，也暂未经过 Apple 公证。** 首次启动可能被 macOS 拦截。本机运行测试已经完成；另一台 Mac 在默认安全设置下的下载与首次启动仍待验证。

## 1. 下载并放到固定位置

1. 从 [1.9.0 Beta 发布页](https://github.com/FishyJ10312/Stowfin/releases/tag/v1.9.0-beta) 下载 `Stowfin-1.9.0-beta-arm64.zip`。
2. 解压后，把「轻扫.app」放入个人应用程序文件夹：`~/Applications/轻扫.app`。没有这个文件夹时可自行创建。
3. 以后从这个位置启动。升级时先退出旧版本，再替换同一位置的应用；保留需要回退的旧版副本。

不要直接从下载目录、解压副本和多个备份位置交替启动或反复授权。

可选的完整性核对：将发布页的 `SHA256SUMS.txt` 放在下载文件旁，在该目录执行：

```sh
shasum -a 256 Stowfin-1.9.0-beta-arm64.zip
```

将输出与校验文件中的同名条目比较。SHA-256 用于核对下载文件是否一致，不代表软件已经通过 Apple 公证或没有缺陷。

## 2. 首次启动

先双击固定位置的「轻扫.app」。如果系统提示无法验证开发者，只有在确认下载来源和文件完整性后，再按 Apple 提供的单个应用允许流程处理：

1. 打开「系统设置 → 隐私与安全」。
2. 找到与轻扫对应的拦截提示，选择「仍要打开 / Open Anyway」。
3. 核对应用名称，完成系统要求的确认。

参考：[Apple：在 Mac 上安全地打开 App](https://support.apple.com/en-us/102445)。该方式是否可用取决于系统和设备管理策略。如果提示应用已损坏、被修改或检测到恶意内容，停止使用该文件，重新核对下载和校验值，并提交反馈。

不需要关闭整个系统的 Gatekeeper、SIP 或其他安全检查。本项目不提供清除下载隔离标记、关闭系统安全评估的安装命令。

## 3. 按应用提示授权

「扫描常用位置」检查下载、缓存和日志。常规文件从 1 MB 起，符合规则的小缓存也会按组列出。如需扩大只读分析范围，可前往空间分析并选择「分析全部位置」。

扫描下载、桌面或文稿等目录时，macOS 可能询问是否允许访问。只为准备扫描的范围授权。清理扫描被拒绝后会打开访问助手，可「选择文件夹」「前往系统设置」「重新检查」。未读取的位置不计入结果，并明确显示「尚未读取」。重新检查沿用原范围，不会偷偷扩大。

授权需要退出重开时，按系统提示操作。重开后，应用会实际检查之前被拒绝的位置；确认恢复访问后按保存范围补扫。仍无法读取的位置继续保留处理入口，不会自动勾选或删除文件。

清理前，轻扫会核对废纸篓是否可读取，以便在意外中断后重新匹配恢复文件。如果出现「无法读取废纸篓」或对应访问提示：

1. 在轻扫中点「前往系统设置」。
2. 进入「隐私与安全 → 完全磁盘访问」，开启「轻扫」。
3. 列表没有轻扫时，点 `+`，选择固定位置的 `~/Applications/轻扫.app`，再开启。
4. 由你本人完成密码或指纹验证。系统要求退出重开时，按提示操作。
5. 回到轻扫，在文件访问助手点「重新检查」；中断清理批次在「清理记录」点「重新核对」。应用会实际重新读取，再更新状态。

参考：[Apple：更改隐私与安全设置](https://support.apple.com/en-my/guide/mac-help/mchl211c911f/mac)。完全磁盘访问范围较广，由 macOS 管理，可随时在同一位置撤销。应用不会自行开启这个权限，也不会要求你把密码交给开发者。

完全磁盘访问不代表所有系统位置都能读取，也不代表这些位置都允许清理。系统限制、未连接的磁盘和未完成的目录仍会单独显示。

## 切换语言

同一个安装包包含 English 和简体中文。窗口顶部的语言菜单可选择「跟随系统」「简体中文」或「English」。设置会保留到下次启动；复核或文件操作中暂不能切换。文件名、路径和原有记录保持原样。macOS 自己的对话框遵循系统或应用的系统语言设置。

## 4. 第一次试用

先新建临时文件夹，放入几份可以丢弃的文件，再选择这个范围扫描。

1. 确认扫描结果可以进入子目录并返回上级。
2. 素材和项目应默认不勾选；添加推荐项不会自动选中这些文件。
3. 主动勾选需要测试的文件，进入复核页，试一次取消单项或整组。
4. 对「需自行确认」的文件，完成二次确认后才移到废纸篓。
5. 打开「清理记录」，恢复这个批次，核对原位置和文件内容。

应用会保存逐项操作日志；重启后核对中断批次，已确认移走的文件会补回恢复入口。尚未处理的项目不会自动继续删除。写入日志失败会停止后续文件操作；待核对项需要重新核对，不会按同名文件猜测恢复对象。

## 5. 升级与恢复

- 新版继续使用固定的安装位置。系统签名身份变化、从源码构建或设备策略变化时，可能需要重新确认权限。
- 历史记录保存在本机 `~/Library/Application Support/QingSweep/`。升级时保留这个目录；其中的操作日志、清理历史和忽略列表不要当成可重建缓存删除。
- 恢复到原位置时不覆盖已有文件。若有冲突，先自行处理占用或改名，再重新检查并恢复。
- 废纸篓暂时无法读取时，恢复访问权限或重新连接磁盘，再到「清理记录」点「重新检查」。
- 文件仍在废纸篓时才可能恢复。清空废纸篓或修改、移动对应文件后，恢复可能不可用。
- 移入废纸篓不会立即释放对应空间；轻扫不会自动清空废纸篓。

## 常见问题

**为什么没有「仍要打开」？**

先尝试打开应用，再按 Apple 官方说明查看设置。受组织管理的 Mac 可能不允许手动放行；提交系统版本和具体提示，等待处理。

**开启权限后仍显示未读取？**

确认授权的是固定位置的轻扫，按系统要求重开后再检查。磁盘断开、目录不存在或系统限制会有不同结果，不要通过重复添加多个应用副本来尝试。

**能清理达芬奇代理吗？**

可以先在工具中查看代理与缓存，再主动选择。请自行确认项目是否仍需要这些文件、原片是否可用；软件不会完整读取达芬奇私有项目数据库来证明“已经没有引用”。

**未公证版能保证在其他 Mac 打开吗？**

目前不能保证。请在 [Issue](https://github.com/FishyJ10312/Stowfin/issues/new?template=bug_report.md) 反馈芯片、系统版本和拦截提示。发布页始终保留 Beta 与暂未公证的标注。
