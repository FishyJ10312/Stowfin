# 隐私与本机数据

[English](PRIVACY.en.md) · 简体中文

适用于本仓库发布的轻扫 1.8.7 Beta。

## 扫描与文件操作

应用在本机读取你选择的目录和已授权位置，用于统计空间、分类、搜索、查重、归档与清理。程序不上传文件内容、文件路径、扫描索引或清理记录，不包含应用自行发送的遥测、广告或账号登录。

## 检查更新

轻扫只有一种网络请求：检查是否有新版本。只在你点「检查更新」时发出；如果你打开「每天自动检查更新」（默认关闭），则每天最多一次。请求是对 `api.github.com/repos/FishyJ10312/Stowfin/releases` 公开发布列表的匿名读取，不发送文件名、路径、扫描结果、硬件信息或任何标识，也不保存 Cookie。GitHub 会像处理普通网页请求一样看到你的 IP 地址。轻扫不会自动下载或安装更新；发现新版本时只会在浏览器中打开发布页。

文件操作和校验会读取实际文件。重复检查、归档校验和恢复核对可能计算文件内容的 SHA-256 摘要。视频检查会在本机读取媒体信息。程序不会把扫描内容提交给云端模型。

语言选择另外保存在 macOS 管理的本机应用偏好设置中。

## 保存在哪里

本机数据保存在 `~/Library/Application Support/QingSweep/`，包括：

- 扫描范围、扫描时间、文件名称与路径、容量、分类、归属及访问状态。
- 可重建的空间索引和清理候选索引。
- 忽略列表、清理历史、批次摘要、逐项操作日志。
- 用于核对文件身份的元数据、校验摘要，以及用户手动确认的原片关联。
- 工具任务记录、增长快照和相关设置。

空间索引可以重建；清理恢复所需的日志和历史不能按普通扫描缓存处理。删除历史或操作日志会影响应用内恢复，不会替你恢复已经移到废纸篓的文件。

## 权限与外部链接

文件夹访问和完全磁盘访问由 macOS 管理，需要用户自行允许。你可以在「系统设置 → 隐私与安全」撤销。授权范围与程序允许执行清理的位置是两套限制；取得权限不会自动选中素材和项目。

应用里的帮助和规则来源链接可能交由浏览器打开。访问 GitHub、Apple 等网站时，由对应网站和浏览器处理网络请求。macOS 自身的系统诊断和权限机制不由轻扫控制。

## 反馈时分享什么

GitHub Issues 是公开的。请只提交问题所需的版本、芯片、系统、操作步骤和已遮挡个人信息的截图。不要上传完整扫描数据库、清理历史、项目文件、证书私钥或系统密码；完整路径中也可能包含个人信息。
